# 架构与路线图

MiniKV 是单机、单进程的持久化键值 RPC 服务。客户端通过 bRPC 和 Protobuf 调用服务层，服务层调用 RocksDB 存储封装。

## 组件边界

- bRPC：连接管理、请求分发、并发控制和 RPC 生命周期。
- Protobuf：消息定义、序列化、服务与客户端 Stub 生成。
- RocksDB：并发键值操作、WAL、LSM 树、后台压缩和数据库锁。
- MiniKV：接口契约、输入校验、错误映射、配置、CLI、资源生命周期和自动化验证。

当前不实现自定义线程池、网络协议解析器、WAL 或 LSM 存储引擎。

## 已实现

- Put / Get / Delete，文本键、二进制值和明确的错误码。
- 默认 WAL 同步写，可配置同步选项。
- 默认回环监听、客户端禁用自动重试。
- 二进制文件导入导出、优雅关闭。
- 存储边界、并发、RPC、异常退出恢复与输出失败回归测试。

## 后续方向

1. 可重复的基准测试：记录硬件、参数、数据集、吞吐、延迟分位数及同步写策略。
2. TTL：先定义数据格式和过期语义，再实现读时判定与后台清理，验证清理和覆盖写之间的并发一致性。
3. 根据测量结果评估独立存储执行队列，以及请求排队和过载行为。

以上为待实施方向，不代表已经实现的能力。复制、分片及分布式一致性暂不纳入当前范围。
